# 云效集成底座

## Goal

建立可配置、可审计、可重试的云效只读集成底座，为需求交接、工时同步和驾驶舱提供稳定数据。

## Deliverables

- 云效配置、人员映射、项目映射、工作项缓存、同步批次数据表。
- 基于 `java.net.http.HttpClient` 的云效客户端和统一错误模型。
- 连接参数支持页面维护；Token 使用服务器密钥加密存储，连接测试不回显密钥。
- 分页、限流重试、幂等入库和同步状态接口。
- 中心版/Region 版路径切换。

## Acceptance

- [x] 未配置时接口明确返回“待配置”，系统其他功能正常。
- [x] 模拟云效服务能完成分页、重试和 429/5xx 契约测试。
- [x] 日志和接口响应不包含 Token。
- [x] 页面可保存版本、服务地址、组织 ID、PAT 和启停状态并执行连接测试。
