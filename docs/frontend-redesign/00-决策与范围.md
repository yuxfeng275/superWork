# 决策与范围

> **历史存档**：迁移已于 2026-09-25 完成，旧 Vue 前端已下线删除。本文仅记录当时决策背景。

## 1. 最终决策

不做一次性 Big Bang Rewrite，也不在 Vue 页面上继续做零散换皮。

采用“**React + Ant Design Pro 6 目标架构下的渐进式前端重做**”：

- 新建 React 前端应用。
- 旧 Vue 应用继续运行，作为生产回滚版本和功能基线。
- 按路由和业务域逐步迁移。
- 后端 API、数据结构、权限语义和业务结果保持不变。
- 交互、信息架构、布局、视觉设计和组件实现允许重新设计。

Ant Design Pro 6、ProComponents 和 Ant Design X 属于 React 体系；当前仓库是 Vue 3 + Vite + Element Plus，因此不能在现有 Vue 工程中直接原生接入这套技术栈。

## 2. 不在本项目范围内

- 不删除旧前端，直到新前端完成生产观察期。（已完成：观察期结束，旧前端 2026-09-25 删除）
- 不调整业务状态机、计算公式、审批规则和角色含义。
- 不借机重做业务需求。
- 不同时引入 Element Plus、Ant Design Vue、Ant Design React 三套 UI 体系。

## 3. 必须保持不变的功能契约

### 路由与权限

- 现有路由路径、深链和独立详情路径保持兼容。
- 登录、退出、Token 过期、401、403 行为保持一致。
- 角色访问、动态菜单、大事儿领域准入保持一致。

### 业务行为

- 需求、任务、缺陷的列表、详情、状态操作和权限边界。
- 大事儿负责人、参与人、周进展、会议模式。
- 营收 H1/H2/全年口径、导入导出、利润和成本计算。
- 商机跟进只追加历史，不覆盖商机备注。
- 云效工作项的来源标签和只读行为。
- 邮件敏感字段、正文安全和同步状态。
- AI 会话、流式输出、工具调用、连接器状态和中断行为。

### 敏感信息

- Token、密码、PAT、邮箱安全密码不回显。
- 配置敏感字段为空时表示保持原值。
- 邮件 HTML、远程图片和脚本不执行。
- AI 工具调用必须保留状态、错误和人工确认边界。

## 4. 技术决策门

在 T02/T03 完成后，只有同时满足以下条件，才继续扩大 React 迁移：

1. React App Shell 能通过登录、权限和动态菜单回归。
2. 需求和任务试点可以完成真实查询、创建、编辑、删除和详情闭环。
3. 新旧页面可以在同一数据集上对比，且已有回归用例可以迁移。

任一条件不满足时，不扩大迁移范围，先修复基础设施或回退到现有 Vue 页面。
