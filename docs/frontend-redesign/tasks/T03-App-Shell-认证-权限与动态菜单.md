# T03 App Shell、认证、权限与动态菜单

## 目标

在没有业务页面迁移的情况下，完成新前端的登录、鉴权、主布局、动态菜单和路由保护。

## 工作项

1. 迁移登录、退出、Token 过期和 401 处理。
2. 迁移角色访问控制和动态菜单树。
3. 迁移大事儿领域准入判断。
4. 建立桌面、平板、390px 移动端三套壳层状态。
5. 实现侧边栏折叠、分组、当前路由高亮和面包屑。
6. 实现全局错误通知、页面级 Loading、Empty、Error。
7. 实现用户菜单、通知入口和深链跳转。
8. 为普通岗位和管理岗位分别建立权限回归。

## 验收标准

- 未登录访问受保护路由跳转登录。
- 无权限角色不能通过 URL 直达管理页。
- 动态菜单和路由权限一致。
- 320px 和 390px 不产生页面级横向溢出。
- 旧版权限 Playwright 用例可以迁移并通过。
