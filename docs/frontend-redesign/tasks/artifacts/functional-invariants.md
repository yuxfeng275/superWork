# 功能不变约束清单

## 写入闭环

- 创建、编辑、删除后必须重新读取或通过可信响应确认真实状态。
- 失败时保留用户输入，不以成功 Toast 覆盖失败。
- 列表、详情、摘要和计数刷新范围必须明确。

## 数据口径

- 营收 H1/H2/全年、含税/未税、销售/交付/成本口径不改变。
- 大事儿完整台账数量不受个人筛选和普通筛选错误影响。
- 工时实际值、计划负荷和数据未知状态不能混淆。

## 权限

- 菜单隐藏不等于权限授予。
- 云效工作项来源为 YUNXIAO 时保持只读。
- 大事儿负责人、参与人、创建者和管理员边界保持一致。
- 401、403、过期权限和迟到请求不能改写当前路由。

## 安全

- Token、PAT、邮箱安全密码、AI 连接器凭证不回显。
- 邮件正文只按纯文本安全渲染。
- AI 工具调用展示执行状态，不默认扩大写权限。
