# 迁移优先级与依赖

## P0：先做

1. React 工程、请求层、鉴权、路由、动态菜单。
2. 设计 Token、页面头部、筛选栏、表格、详情抽屉。
3. 需求、任务、缺陷、项目垂直试点。
4. 权限、敏感字段和移动端溢出回归。

## P1：核心业务域

1. 大事儿和周报。
2. 营收、BU 驾驶舱、KPI。
3. 邮件管理。
4. 商机、报价和客户。

## P2：最后迁移

1. 系统管理页面的视觉统一和复杂编辑器。
2. AI 助手和连接器的 Ant Design X 重做。
3. 生产切换、旧版下线和文档归档。
