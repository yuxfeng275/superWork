# T06～T11 后续业务域与生产切换

## T06：大事儿、周报、邮件

- 拆分大事儿登记、详情、周更新、会议展示和演示模式。
- 保留负责人/参与人权限和个人快捷筛选语义。
- 邮件正文保持纯文本安全渲染，敏感配置不回显。

## T07：营收、驾驶舱、KPI

- 先冻结含税/未税、H1/H2/全年、销售和成本口径。
- 营收矩阵不得强行套用普通 ProTable。
- 迁移导入、导出、成本、交付和待确认状态。

## T08：商机、报价和客户

- 跟进历史必须使用追加接口。
- 报价计算、策略和报价单详情保持原有 payload 和状态流转。
- 客户、联系人和项目关联关系不改变。

## T09：系统管理和配置

- 用户、角色、菜单、工作流、配置和连接器按权限迁移。
- 角色固定目录和兼容角色显示保持现有 UI 合约。
- 密码、Token、PAT 等敏感输入永不回显。

## T10：AI 助手和连接器

- 使用 Ant Design X 重做会话列表、消息流、工具调用和输入区。
- 保留流式中断、错误、重同步和连接器状态。
- 任何有副作用的 AI 行为都需要预览、确认和审计证据。

## T11：回归、性能和切换

- 全量迁移 25 个现有 E2E 用例。
- 增加多尺寸视觉快照和页面溢出检查。
- 建立构建体积、首屏加载和错误率基线。
- 新旧前端独立部署，按路由启用。
- 生产观察期内保留旧版回滚入口。
