# T04 设计 Token、主题和通用业务组件

## 目标

形成唯一视觉源，替代现有蓝色/紫色/页面硬编码并存的状态。

## 工作项

1. 确认蓝色企业运营台视觉方向。
2. 建立颜色、字体、间距、圆角、阴影、层级和动效 token。
3. 配置 Ant Design `ConfigProvider` 和 ProLayout 主题。
4. 建立 PageHeader、FilterBar、StatusTag、MetricCard、DataTable、DetailDrawer。
5. 建立统一 Confirm、Result、Empty、Error、Skeleton。
6. 建立表单校验、错误提示和未保存变更模式。
7. 建立可访问性基线：label、focus、键盘顺序、语义按钮。
8. 为 1440、1024、768、390、320 生成组件状态截图。

## 验收标准

- 新页面不直接写业务颜色和任意圆角。
- 通用组件有 Story/示例或独立测试页面。
- 组件覆盖 loading、empty、error、disabled、hover、focus 状态。
- 视觉评审通过后才能进入 T05。
