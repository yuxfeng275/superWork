# 邮件管理部署与使用

## 功能范围

- 每位员工绑定自己的阿里云企业邮箱，凭据使用第三方客户端安全密码。
- 只读同步 Inbox；首次同步最近 7 个自然日，之后每小时增量同步。
- 每天 08:00（Asia/Shanghai）生成昨日摘要；DeepSeek 不可用时使用规则摘要。
- 企业微信内部应用点对点推送摘要概览、重要事项和系统链接；未配置或未映射时不影响页面查看。
- 附件只保存文件名、类型和大小，不下载附件内容。

## 必填生产配置

```bash
# 生成一次并永久保存，后续不可随意更换，否则已绑定邮箱的安全密码无法解密
openssl rand -base64 32
EMAIL_CREDENTIAL_ENCRYPTION_KEY=<上一步输出>
```

## 页面集成配置

管理角色进入“系统 → 配置管理”，打开“邮件摘要与推送”配置组，可维护：

- DeepSeek：启用状态、服务地址、模型、API Key。
- 企业微信内部应用：启用状态、服务地址、CorpId、AgentId、Secret。
- 系统访问地址：企业微信摘要消息中使用的系统链接根地址。

API Key 和 Secret 使用 AES-256-GCM 加密保存到 `email_integration_config` 表，保存后页面和 API 只返回“已配置”状态，不返回明文或密文。更新其他字段时，敏感字段留空会保留现有密钥。

页面同时提供 DeepSeek 和企业微信连接测试。DeepSeek 未配置或测试失败时，邮件同步不受影响，摘要自动使用规则降级；企业微信未配置或推送失败时，摘要仍保留在系统页面。

只有 `EMAIL_CREDENTIAL_ENCRYPTION_KEY` 作为服务端主加密密钥保留在基础设施配置中。该密钥不属于业务集成配置，不能保存到同一个数据库中，否则无法安全解密数据库内的邮箱安全密码、DeepSeek API Key 和企业微信 Secret。

## 阿里云企业邮箱前置条件

1. 企业管理员已允许 IMAP 服务。
2. 员工在阿里云企业邮箱安全设置中生成第三方客户端安全密码。
3. 员工在系统“邮件管理”中填写完整邮箱地址与该安全密码。
4. 不得填写网页登录密码。

## 定时任务

```bash
EMAIL_SYNC_CRON='0 0 * * * *'
EMAIL_DIGEST_CRON='0 0 8 * * *'
```

默认均使用 Asia/Shanghai 时区。页面提供“立即同步”和摘要重算入口。

## 网络要求

- 后端容器允许访问阿里云企业邮箱 IMAPS 端口（通常为 TCP 993）。
- 启用 DeepSeek 时允许访问页面中配置的 DeepSeek 服务地址 HTTPS 端口。
- 启用企业微信时允许访问企业微信 API 的 HTTPS 端口。

## 安全说明

- 邮箱安全密码采用 AES-256-GCM 加密落库，接口只返回 `credentialConfigured`。
- 邮件正文仅以纯文本展示，不渲染邮件 HTML。
- DeepSeek 接收纯文本正文，不接收邮箱凭据、HTML 源码、远程图片或附件。
- 邮件、摘要和同步状态全部按当前 JWT 用户强制隔离；管理角色不默认获得其他员工正文访问权。
## AI 解读与每日摘要

- 每封邮件详情提供“邮件原文 / AI 解读”Tab。首次点击 AI 解读会使用配置管理中保存的 DeepSeek 自动生成并持久化结果。
- 解读内容包含核心结论、发件人意图、关键要点、待办、风险和回复建议，可重新生成。
- 每日摘要按日期持久化，页面通过“摘要总览 / 重要邮件 / 待办事项 / 风险提醒 / 回复建议”Tab 展示；总览增加邮件指标、结论、生成模型和更新时间，分类内容改为可读卡片并保留查看邮件入口。
## 项目智能分组

- 系统读取当前有效项目，以邮件标题、发件人和正文为依据批量调用 DeepSeek 分类。
- 只接受真实项目 ID 且置信度不低于 65%；无法判断、置信度不足或非法项目统一归入“未分组”。
- 新邮件同步后自动分组，页面可手动补分组或重新分组全部邮件。
- 邮件列表左侧支持“按项目 / 按发件人公司”切换。项目模式支持未分组筛选；公司模式按发件邮箱域名聚合并由后端筛选。

## 钉钉式 AI 邮件纪要

每日摘要按 AI 会议纪要方式生成并持久化：高层总览、议题归纳、决策/进展、重要邮件、待办、风险、回复建议。议题会合并多封相关邮件并保留原邮件引用，进展状态限定为已完成、推进中、待确认。

## 行动闭环（Email → Action → Loop）

- 摘要的每条待办/风险卡片提供「转任务」「转事项」按钮：自动带入标题、来源邮件链接、负责人（当前用户），转化记录落 `email_email_action`（幂等，重复转化返回既有记录）。
- 任务状态变为「已完成」、事项变为「已解决/已关闭」、大事儿变为「已完成」时，对应摘要条目自动标记「已闭环」并划线；摘要总览显示闭环进度（如 闭环：2/5）。
- 转化目标：任务（Task，默认挂当前用户）、事项（Issue，风险默认严重程度「中」）、大事儿（BU Key Matter）。
- 摘要底部提供「有用 / 没用」一键反馈，落 `email_daily_digest.feedback`，用于摘要质量迭代。
- 每日 08:00 企微摘要推送含闭环进度行（"闭环进度：N 个待办/风险，已闭环 M"）。
- 风险邮件即时推送：同步落库后异步扫描最近 30 分钟新邮件，命中风险信号词（投诉/故障/赔付/违约/紧急/urgent/incident 等）立即企微点对点推送，不等次日摘要；未配置企微/未映射时静默降级。

## SMTP 回复

- 邮件详情「AI 解读」Tab 的「建议回复」卡片可直接编辑草稿并通过绑定的企业邮箱 SMTP（smtp.qiye.aliyun.com:465 SSL）发送，复用已存加密凭据。
- 发送记录落 `email_sent_reply`，挂在原邮件会话下；失败记录含脱敏错误信息，可重试。
- `email.smtp-port` 配置项可覆盖默认端口 465。

## 项目反向挂载邮件流

- 项目详情抽屉新增「相关邮件」卡片区：展示该项目近 5 封往来邮件（标题、时间、预览）；用户未绑定邮箱或无邮件权限时静默降级不显示。

## 本月价值面板

- 邮件管理页顶部「本月价值」条：本月转化数、待办闭环率（北极星指标）、摘要好评数、平均响应时长（收到 → 回复/转化的分钟数）。
- 数据来源 `GET /api/emails/metrics`，全部按当前用户隔离统计。

## AI 助手邮件行动工具

AI 助手新增三个邮件工具（与只读的 `search_my_emails`/`read_my_email` 互补）：

- `get_my_email_digest`：查询某天（默认昨天）的邮件摘要，返回总览/待办/风险/回复建议，条目带 emailId 供后续转化。
- `convert_email_item_to_task`：把摘要条目转成任务（TASK，默认）或事项（ISSUE）；执行前系统提示词要求 AI 向用户复述并确认。
- `reply_my_email`：经用户确认的正文通过绑定邮箱 SMTP 回复原发件人。
