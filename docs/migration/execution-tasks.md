## 每个任务的完成定义

1. 代码：真实接口接入，类型通过，未引入未授权的额外功能。
2. 交互：加载、空、错、禁用、焦点、成功反馈齐全；列表操作能看到真实状态变化。
3. 回归：`npm run tsc`、`npm run build`、真实浏览器关键路径通过。
4. 文档：在迁移方案和本清单中补充接口、路由、权限、验证日期与未验证项。
5. 发布：只在该域验收完成并确认回退路径后，才将入口切换到新工程。
