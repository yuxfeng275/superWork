# 云效集成配置

本系统负责 BU 方向、需求前期流程和最终分析；云效负责研发执行数据。
云效连接参数可在管理页面维护。个人访问令牌使用服务器独立密钥执行
AES-256-GCM 加密，接口和页面都不会回传令牌原文。

## 1. 服务器密钥

部署环境必须设置页面令牌加密密钥：

```bash
YUNXIAO_CONFIG_ENCRYPTION_KEY=<32字节随机密钥的Base64>
```

原有 `YUNXIAO_ENABLED`、`YUNXIAO_EDITION`、`YUNXIAO_BASE_URL`、
`YUNXIAO_ORGANIZATION_ID` 和 `YUNXIAO_TOKEN` 继续作为兼容兜底。
页面保存配置后，非敏感参数以页面值为准；页面未录入令牌时仍可使用环境变量令牌。

## 2. 页面配置

使用具有 `yunxiao:manage` 权限的管理账号进入
`BU驾驶舱 -> 云效配置`：

1. 选择中心化版本或专有云版本，填写服务地址。
2. 中心化版本填写组织 ID；专有云版本无需组织 ID。
3. 录入 PAT，保存后输入框保持为空；留空再次保存不会覆盖原令牌。
4. 点击“测试连接”，确认当前 PAT 能获取云效用户信息。
5. 新增项目映射时，系统自动分页拉取云效项目；按项目名称或编码搜索选择，无需手工填写项目 ID。
6. 新增人员映射时，系统自动分页拉取启用中的云效组织成员；分别选择本地人员和云效人员，无需手工查找用户 ID。
7. 启用集成后执行同步。

拉取项目列表只要求已保存服务地址、组织 ID（中心化版本）和 PAT，不要求先开启同步。
映射记录保存云效返回的稳定项目 ID，后续作为工作项接口的 `spaceId` 使用。
一个本地项目只能配置一个云效项目；多个本地项目可以共享同一个云效项目。共享空间在
每轮同步中只扫描一次，各本地映射共享本次同步结果。
人员映射保存云效成员的稳定 `userId`（不是组织成员 `id`），后续作为工作项负责人和工时归属人的关联键。

PAT 至少需要以下权限：

- 项目协作 / 工作项：只读；需要自动创建需求时为读写
- 项目协作 / 实际工时：只读
- 项目协作 / 预计工时：只读
- 组织管理 / 组织成员：只读

外部接口遇到 429 或 5xx 时最多自动重试 3 次。任一启用项目尚未成功同步或最近同步
失败时，已映射人员的工时状态显示为“数据未知”，不会按“未填写”统计。
云效实际工时日期兼容 ISO、Unix 秒和 Unix 毫秒格式，并统一按上海时区归档；项目重新
同步成功后会清除历史失败信息。
已有项目映射改选其他云效项目时，系统会先清除该本地项目关联的旧工作项、实际工时和
预计工时缓存，并重置同步状态，避免不同云效项目的数据混在一起。
工时同步统一扫描需求、任务和缺陷（`Req,Task,Bug`），并查询最近 7 天内修改过的
工作项；首次成功后从上次同步日期向前重叠 1 天增量扫描。云效新增或修改实际工时时会
更新工作项修改时间，因此可覆盖每日填报与历史补填，同时避免每小时遍历项目全部历史工作项。

需求从“待确认”进入“开发中”后，系统会创建本地交接事件。云效配置完整时，
任务会异步创建；配置不完整或调用失败时，本地需求状态保持不变，可重试或手工绑定。

## 3. 管理口径

- 每个工作日 18:30 生成缺填预警。
- 下一工作日 10:00 固化前一工作日结果；节假日和调休按工作日日历判断。
- 实际投入率反映所选历史周期，不作为绩效评分。
- 未来计划负荷按预计工时负责人计算；缺少云效预估时回退本地未完成任务，并在页面标明。
- 人员已有云效活动工作项但未登记预计工时时，页面仍展示这些工作项，计划负荷标记为
  “未知”，不按“可承接”统计。
